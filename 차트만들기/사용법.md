# 차트만들기 — 종목명을 넣으면 브로셔 2번 차트(최근 125거래일) 이미지를 만들어 줍니다

## 준비
- 이 저장소를 PC에 내려받아 압축을 풉니다. (`tornado_screener.py`가 이 폴더의 바로 위 폴더에 있어야 합니다.)
- Python 3, `pip install finance-datareader pandas numpy`, Windows의 Microsoft Edge가 필요합니다.

## 사용
- `차트만들기.bat`을 더블클릭하고 종목명(일부 가능) 또는 6자리 코드를 입력합니다.
- 또는 터미널에서: `python make_chart.py 아시아나IDT`
  - `--기준일 2026-11-19` : 그 날짜까지의 봉으로 그림
  - `--급등 20` : 급등일 라벨 기준(하루 상승률 %, 기본 15)

## 결과
`차트_출력\종목명_차트.png` 와 `.html`

## 구성
종가 + 5·20·60·150일선 + 토네이도 1·2번선(합친 띠) + 3번선(진한 파랑 띠, BBandsUP 120~129) + 4번선(갈색 띠, BBandsUP 240~249) + 번개선 A·B + 최근 12일 캔들 + 거래량.
장중(16시 전)이면 직전 확정 봉 기준이고 오늘 시세는 점선으로 따로 표시합니다.
조건 분류용 참고 자료이며 투자 권유가 아닙니다.
